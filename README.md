# PhotoFilter

PhotoFilter is a desktop image-processing application built with Java and Java Swing. It allows users to open images in supported formats and apply a variety of filters and image adjustments through a graphical user interface.

## Features

- **Grayscale:** Convert images to grayscale.
- **Ordered Dithering:** Reduce image color depth using an ordered dithering technique.
- **Auto-Leveling:** Adjust image tonal levels to improve contrast.
- **Invert:** Invert image colors to produce a negative effect.
- **Floyd–Steinberg Dithering:** Reduce color depth while distributing quantization error to neighboring pixels.
- **Gamma Correction:** Adjust image brightness and tonal response using gamma correction.
- **Brightness Adjustment:** Increase or decrease image brightness.
- **Sepia Tone:** Apply a warm, vintage-style sepia effect.

## Supported Image Formats

- PNG (`.png`)
- JPEG (`.jpg`, `.jpeg`)
- Bitmap (`.bmp`)

## Requirements

- Java Development Kit (JDK)

## How to Run

1. Clone or download this repository.
2. Ensure that Java is installed on your system.
3. Open the project in your preferred Java IDE.
4. Build and run the main application class.
5. Open an image in a supported format.
6. Select a filter or image adjustment to apply it to the image.

## Technologies Used

- **Java** – Application logic and image processing.
- **Java Swing** – Desktop graphical user interface.
- **Image Processing Algorithms** – Dithering, tonal adjustments, and color transformations.
